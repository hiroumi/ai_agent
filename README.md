# AIエージェント人事部（Agent HR）— デモ

AI 社員（AI エージェント）の **採用から評価まで** を支える「AIエージェント人事部」のデモです。
エージェンティックAI BootCamp@高知（2026-10-31〜11-01）チーム5 の作品です。

## 解決したいこと

- 何を AI に任せればいいかわからない
- 複数の AI エージェントが動く姿をイメージできない
- AI が作ったもの（Claude Code などでの並行開発）に理解が追いつかない

## しくみ

人の会社と同じように、AI 社員も「採用 → 配置 → 評価 → 育成」。

1. **業務の棚卸し** — 会社の説明・部署・ツールから、AI に任せやすい仕事を見つける
2. **採用計画** — 必要な AI 社員を組織図で提案。採用する／見送るを選ぶ
3. **自動配置** — 働く場所・タイミング・報告先つきで配置（試用期間 2 週間）
4. **デイリー／マンスリーレポート** — 稼働・結果・費用対効果・来月の提案
5. **タスクの評価** — 使った人の「いいね／イマイチ」と、AIエージェント人事部長の自動評価
6. **人事評価とお伺い** — 合格 1 件あたりのコストと品質で評価。配置換え・契約終了は人に伺ってから
7. **CTO AI** — 並行開発の中身を毎朝わかる言葉で解説し、開発方針を相談できる

## デモの開き方

`index.html` をダウンロードして、ブラウザで開くだけです（ネット接続不要・1 ファイル）。
ランディングページの「無料で試してみる（デモ）」→ ① で「地方の SaaS スタートアップ」の例ボタンを押すと、最後まで進められます。

## 注意

- 画面だけのデモです。提案や評価はキーワードと用意した例にもとづくもので、実際の AI は呼び出していません
- 数字・料金・評価結果は、すべてデモ用の例（試算）です
